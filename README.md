# Creative-Component

Slides and paper for **Analysis of a Card-Shuffle Stream Cipher**, Capt Scott D. Russell's M.S. Cybersecurity creative component at Iowa State University (major professor: Dr. Thomas E. Daniels).

- **Site:** https://captainrussell.github.io/Creative-Component/
- **Slides:** https://captainrussell.github.io/Creative-Component/slides/ is one self-contained HTML file. Click or use the arrow keys to step through; press F for full screen, S for the speaker view, H for help.
- **Paper:** https://captainrussell.github.io/Creative-Component/Russell_2026_Card-Shuffle-Stream-Cipher-Analysis.pdf

These files are published from a private working repository by `publish_site.py`. Edit them there, not here.
